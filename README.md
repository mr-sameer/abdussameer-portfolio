# Abdus Sameer — research portfolio

A fast static portfolio for technology-company analysis. It is designed to deploy free on GitHub Pages.

## Publish it with GitHub Pages

1. Create a GitHub repository and upload these files.
2. In the repository: **Settings → Pages → Deploy from a branch → main / root**.
3. Update the contact email in `index.html` if `hello@abdussameer.com` is not the address you want to receive messages at.
4. Add a new analysis by copying an existing file in `analysis/`, then add its card to `index.html`.
5. Submit `https://abdussameer.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.

## Content rules

Keep every analysis original, date it, link to primary sources, separate facts from opinions, and show risks alongside the thesis. Never present it as financial advice.

## Before launch

Add a real domain, Google Search Console, Bing Webmaster Tools, a favicon, and an analytics provider. Submit the generated sitemap once the site has more than a few pages.
